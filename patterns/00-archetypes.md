# 공통 원형 패턴

계열을 가로질러 되풀이되는 **리듬 골격**입니다.
계열별 파일의 장르들은 대부분 이 원형 중 하나를 상속합니다.

표기 규칙과 스윙·그리드 한계는 [README.md](README.md) 참조.

---

## 1. Four-on-the-floor 계열

**House / Techno / Disco / Trance 기본형**
```
kick   X---X---X---X---
clap   ----X-------X---
chat   x-x-x-x-x-x-x-x-
ohat   --x---x---x---x-
```
오픈햇 뒷박(2·6·10·14)이 추진력의 원천입니다. 킥만으로는 행진이 됩니다.

**Techno 변형** — 퍼커션을 줄이고 킥을 짧게
```
kick   X---X---X---X---
chat   --x---x---x---x-
perc   ------x-------x-
```

**Disco Funk 변형** — 오픈햇 + 활발한 16분 베이스
```
kick   X---X---X---X---
snare  ----X-------X---
ohat   --x---x---x---x-
bass   x-xx-x-xx-xx-x-x
```

**Psytrance** — 킥 사이를 베이스 3연타가 채움
```
kick   X---X---X---X---
bass   -xxx-xxx-xxx-xxx     킥이 울릴 때는 반드시 비움 (사이드체인 필수)
ohat   --x---x---x---x-
```

## 2. Backbeat 계열 (2·4박 스네어)

**Rock / Pop 기본형**
```
kick   X-----x-X-------
snare  ----X-------X---
chat   x-x-x-x-x-x-x-x-
```

**Punk** — 8분 전부, 다운스트로크
```
kick   X-x-X-x-X-x-X-x-
snare  ----X-------X---
chat   xxxxxxxxxxxxxxxx
```

**Blast Beat** (Death / Black Metal) — 킥·스네어 16분 교대
```
kick   X-X-X-X-X-X-X-X-
snare  -X-X-X-X-X-X-X-X
```

**Motorik** — 킥과 스네어가 한 박씩 교대, 변화 없음
```
kick   X-------X-------
snare  ----X-------X---
chat   x-x-x-x-x-x-x-x-
```
8마디, 16마디가 지나도 아무것도 변하지 않는 것이 핵심입니다.

## 3. Hip Hop 계열

**Boom Bap** — 스윙 노브 30~45 필수
```
kick   X-----x---X-----
snare  ----X-------X---
chat   x-x-x-x-x-x-x-x-
```

**Trap / Drill / Phonk (하프타임)** — 스네어는 3박 하나뿐
```
kick   X-----x-X-----x-
snare  --------X-------
clap   --------x-------
chat   x-xxx-x-x-xxx-xx     16분 기본 + 롤
808    0-------5-------     길게 지속, 멜로디 담당
```
킥은 **짧게**(감쇠 0.2~0.4초, 튠 −1~0). 808에 저역을 양보해야 합니다.

**Lo-fi Hip Hop** — 붐뱁 골격 + 강한 스윙
```
kick   X-------x-X-----
snare  ----X-------X---
chat   x-x-x-x-x-x-x-x-     스윙 노브 40~50
```

## 4. Halftime · Bass 계열

**Dubstep** (140 BPM, 체감 70)
```
kick   X-------X-------
snare  --------X-------
chat   --x---x---x---x-
```
Trap과 킥 배치가 다릅니다. 덥스텝 킥은 1박과 3박, 트랩은 1박 + 엇박.

**Future Bass** — 스네어가 8분으로 촘촘
```
kick   X-------X-------
snare  --------X-------
clap   ----x---X---x---
```

**Drum & Bass** (174 BPM, 1마디 축약형)
```
kick   X---------X-----     (0, 10)
snare  ----X--x----X--x     (4, 7고스트, 12, 15고스트)
chat   --x---x---x---x-     8분 뒷박
ohat   --------------x-
```
고스트 스네어(7·15)가 없으면 DnB가 아니라 그냥 빠른 브레이크비트입니다.

**UK Garage 2-step** — 스윙 노브 30~40
```
kick   X---------X-----
snare  ----X-------X---
chat   -x-xx-x--x-xx-x-     셔플된 16분, 불규칙
```

## 5. 클라베 · 트레시요 계열

라틴·카리브·아프리카 계열의 공통 뼈대입니다. 이것 하나를 이해하면
그 계열 대부분의 리듬을 설명할 수 있습니다.

**Tresillo (3+3+2)** — 8분음표를 3-3-2로 나눔
```
       X-----X-----X---     (0, 6, 12)
```
레게톤·아프로비츠·저지클럽·베일리펑크가 전부 이것을 뼈대로 씁니다.

**Son Clave 3-2** (2마디가 최소 단위)
```
bar1   X-----X-----X---     (0, 6, 12)   ← 3-side, 트레시요와 동일
bar2   ----X---X-------     (4, 8)       ← 2-side
```
2-3 방향은 두 마디를 맞바꾸면 됩니다.
**살사에서 클라베 방향은 곡 전체에 걸쳐 바뀌지 않습니다.**

**Dembow / Reggaeton**
```
kick   X-------X-------
snare  ---x--x----x--x-     (3, 6, 11, 14)
chat   x-x-x-x-x-x-x-x-
bass   0--0--0-5--5--3-     (0, 3, 6, 8, 11, 14)
```
각 박을 16분 4등분했을 때 1박의 **"a"**(3) → 2박의 **"&"**(6) →
3박의 **"a"**(11) → 4박의 **"&"**(14)에 떨어집니다.
10·13으로 찍으면 그루브가 한 스텝씩 앞으로 밀려 다른 리듬이 됩니다.

**Afrobeats**
```
kick   X-----X---X-----     트레시요 변형
snare  --------X-------     또는 림 3박
shkr   x-xxx-xxx-xxx-xx     셰이커 16분이 실제 그루브를 만듦
perc   ---x--x----x--x-     콩가·로그 계열
```
킥·스네어는 성기고, **셰이커와 퍼커션이 그루브를 담당**합니다.

**Amapiano**
```
kick   X---X---X---X---
shkr   --x-x---x-x-x-x-     셔플 필요 (스윙 노브 20~35)
log    ----x-------x-x-     로그 드럼: 사인 서브 + 빠른 피치 하강
```

**Samba** (2/4 두 마디를 16스텝에 압축)
```
surdo  ----X-------X---     2박 강세 = 삼바의 무게중심
tamb   x-xxx-xxx-xxx-xx
```

## 6. 자메이카 계열

**Reggae One Drop** — 1박을 비우는 것이 정의
```
kick   --------X-------
snare  --------X-------     림샷, 킥과 동시
skank  --x---x---x---x-     기타·오르간 뒷박
```
1박에 킥을 넣는 순간 **Steppers**가 되고 다른 장르가 됩니다.

**Reggae Steppers** — 킥 4박 전체
```
kick   X---X---X---X---
snare  --------X-------
skank  --x---x---x---x-
```

**Ska**
```
kick   X---X---X---X---
skank  --x---x---x---x-     뒷박 8분 = 스카의 엔진
```

**Rocksteady** — 스카를 늦추고 베이스를 키움
```
kick   X-------X-------
snare  ----X-------X---
skank  --x---x---x---x-
```

## 7. 그 밖의 유용한 골격

**Funk — "on the one"**
```
kick   X-------X-x-----     1박에 모든 것이 집중
snare  ----X-------X---
chat   xxxxxxxxxxxxxxxx     16분, 액센트 불규칙
```
1박에 킥·베이스·기타·혼을 동시에 꽂고 나머지는 비웁니다.
여백이 그루브를 만듭니다.

**New Jack Swing** — 스윙 16분 + 게이트 스네어
```
kick   X-----x-X-x-----
snare  ----X-------X---     게이트 리버브 필수
chat   x-x-x-x-x-x-x-x-     스윙 노브 30~40
```

**Train Beat** (Honky-tonk)
```
kick   X-------X-------
snare  xXxxxXxxxXxxxXxx     16분 롤, 2·4박 강세
```

**Moombahton** — 뎀보우를 108 BPM으로
```
kick   X-------X-------
snare  ---x--x----x--x-
synth  하우스 신스 스탭
```

**Cumbia** — 과차라카 뒷박 액센트
```
kick   X---X---X---X---
snare  ---x---x---x---x
chat   x-x-x-x-x-x-x-x-
```

**Tango** — 마르카토, 4박 모두 짧게 끊어서
```
kick   X---X---X---X---
tom    X---X---X---X---
```
스윙이 전혀 없고 각 음이 짧게 끊기는 것이 특징입니다.
