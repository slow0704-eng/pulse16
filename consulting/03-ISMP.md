**F-301 드럼 GM 매핑 (확정 필요 항목)**

현행 7트랙을 GM 드럼 노트로 옮길 때 `perc` 트랙이 문제입니다.
엔진 8종(셰이커·탬버린·클라베·우드블록·귀로·카바사·아고고·아이언)이
각각 다른 GM 노트를 써야 하므로 **트랙이 아니라 엔진 기준으로 매핑**합니다.

| 트랙/엔진 | GM 노트 |
|---|---|
| kick | 36 |
| snare (body/crack/tight/lofi) | 38 |
| snare (rim) | 37 |
| snare (brush) | — **GM1 에 브러시 노트가 없음** |
| clap | 39 (Hand Clap) |
| chat / ohat | 42 / 46 |
| tom (analog/synth/wood) | 45 |
| tom (conga/bongo/timbale) | 63 / 60 / 65 |
| tom (cowbell) | 56 |
| tom (logdrum) | 41 (근사 — GM 에 로그드럼 없음) |
| perc (shaker/cabasa/tamb) | 70 / 69 / 54 |
| perc (clave/woodblock) | 75 / 76 |
| perc (guiro/agogo) | 73 / 67 |
| perc (iron) | 56 (근사 — GM 에 아이언 없음) |

**GM1 에 대응 악기가 없는 것 — 근사 처리 대상**

| 엔진 | 사정 | 선택지 |
|---|---|---|
| snare/brush | GM1 에 브러시 노트 없음 (GM2 에는 있음) | 38(Acoustic Snare) + 벨로시티 낮춤 / GM2 확장 사용 |
| tom/logdrum | 대응 악기 없음 | 41(Low Floor Tom) 근사 / 별도 음원 지정 |
| perc/iron | 대응 악기 없음 | 56(Cowbell) 근사 / 별도 음원 지정 |

> 이 셋은 **MIDI 로 내보내는 순간 원래 소리를 잃습니다.**
> 시드 JSON(F-302)에는 실제 엔진명이 그대로 남으므로,
> AI 프롬프트에서 "log drum", "brake drum" 을 명시해 보완합니다.
> 설계 시 확정하고 문서에 남기십시오.

**F-502 판정 기준 (초안)**

| 지표 | 합격 | 근거 |
|---|---|---|
| 적분 라우드니스 | −16 ~ −12 LUFS | 스트리밍 표준(−14) ±2 |
| 트루피크 | ≤ −1.0 dBFS | 인코딩 여유 |

| DC 오프셋 | < 1e-3 | 기존 하네스 기준과 동일 |
| 클리핑(플랫) | 0 | 기존 하네스 기준과 동일 |

새 지표를 만들지 않고 기존 도구를 그대로 씁니다.

### 2.8 제약 사항

| ID | 제약 |
|---|---|
| CO-01 | 16스텝 그리드 — 셋잇단·크로매틱 표현 불가 (melody/00-analysis.md §4) |

이 한계를 보완해 주는 구조이므로 치명적이지는 않으나,
"MIDI 만으로 완성곡" 을 기대하면 안 됩니다.

## 6. 발주 시 유의 사항 (외주 전환 대비)

자체 개발을 전제로 했지만, 일부를 외주로 돌릴 경우의 유의점입니다.

| 항목 | 유의점 |
|---|---|
| 음악 도메인 | **외주하기 어렵습니다.** 장르 판단이 필요하고 정답이 문서에만 있습니다. 라이브러리 확장(F-100)은 자체 수행 권장 |
| 익스포트 | 외주 가능. 규격(SMF·시드 JSON)만 확정하면 됨 |
| 백엔드 | 외주 가능. 가장 표준적인 부분 |
| 품질 게이트 | 기존 MCP 자산 이해가 필요. 인수인계 문서 필요 |
| AI 연동 | **약관 리스크가 있어 계약서에 책임 소재를 명시**해야 함 |
