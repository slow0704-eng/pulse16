## 이 산출물이 단정하지 않는 것

기획서가 사실처럼 적으면 위험한 항목입니다. **반드시 별도로 확인한 뒤**
수치를 채워 넣어야 합니다. ISP §7 위험관리에 같은 목록이 있습니다.

1. **Suno 의 공식 API 제공 여부와 상업적 이용 조건.**
   요금제별로 생성물의 상업적 이용 권리가 다르고, 서드파티 래퍼는
   이용약관 위반 소지가 있습니다. 계약 조건을 직접 확인해야 합니다.
2. **AI 생성물의 국내 저작물성.** 인간의 창작적 기여 정도에 따라 판단이
   갈립니다. 이 파이프라인은 "사람이 선율·화성·편성을 정하고 AI 가 음향을
   렌더링" 하는 구조라 유리한 편이지만, **법률 자문이 필요합니다.**
3. **음원 유통사·신탁단체의 AI 생성물 수용 정책.** 유통사마다 다르고
   바뀝니다. 실제 등록을 시도해 봐야 확정됩니다.
4. **시장 규모·경쟁 수치.** 이 문서에는 넣지 않았습니다. 근거 없는 숫자를
   적느니 비워 두는 편이 낫습니다.

위 네 가지는 **1단계 착수 전 선결 과제**로 로드맵에 넣었습니다.
