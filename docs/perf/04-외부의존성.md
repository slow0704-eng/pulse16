## 3. 개선안

### 3-1. [권장 · 즉시] 폰트 내부화 — 오리진 2개 제거

* **라이선스 문제 없음.** Barlow · Barlow Condensed · Space Mono 는 SIL OFL 1.1 입니다
  (Google Fonts 배포본은 OFL 또는 Apache 2.0 만 있습니다). 재배포에 필요한 것은
  **OFL 사본 동봉**뿐입니다.
* **방법** — woff2 5개를 `fonts/` 에 넣고 `styles/tokens.css` 에 `@font-face` 를 직접 씁니다.
  `pulse16-mk16.html:8-10` 세 줄(preconnect 2 + stylesheet 1)을 **삭제**합니다.
* `font-display: swap` **유지** — `02` 문서가 CLS 0 을 실측해 뒀으므로 회귀 감시 지표가 있습니다.
* 라틴 서브셋만 남기면 **101.8 → 약 40 KB** 〈추정〉. 한글은 이 폰트들에 없고
  UI 한국어는 어차피 시스템 폰트로 떨어지므로 **손실이 없습니다.**
* **효과** — 오리진 −2, 요청 −6, `HTML → CSS → woff2` **3단 직렬 사슬 소멸**,
  `file://` 오프라인에서도 폰트가 나옴.

### 3-2. [권장 · 즉시] Tone.js 내부화 — 오리진 1개 제거, `HAS_TONE` 이 항상 참

* **라이선스 문제 없음 — MIT** (`api.github.com/repos/Tonejs/Tone.js` 확인). `LICENSE` 를 함께 둡니다.
* **방법** — `vendor/tone-14.7.77.js` (원본 350 KB) 로 받아 두고
  `pulse16-mk16.html:11` 을 로컬 경로로 바꿉니다. **버전을 파일명에 박으십시오** —
  `02` 문서 §6.2 가 지적한 캐시 무효화 혼란을 파일명 하나로 없앨 수 있습니다.
* **트레이드오프 하나** — cdnjs 는 brotli 65.2 KB 인데 GitHub Pages 는 gzip 이라
  **전송이 약 +15 KB** 늘어납니다〈추정〉. 대신 **새 오리진 핸드셰이크 3 RTT** 가 사라져
  느린 회선에서는 오히려 이득입니다.
* **효과** — 오리진 −1. `file://` 오프라인에서 `HAS_TONE` 이 **true** 가 되어
  §2 표의 «비활성» 3개가 전부 살아납니다.

> 3-1 과 3-2 를 하면 **첫 방문 오리진이 3개 → 0개**, 즉 자기 자신뿐이 됩니다.

### 3-3. [권장 · 지금 고칠 것] `CASIO_URLS` 에서 `G#2` 제거 — 3줄

`config.js:37-39` 의 `'G#2':'Gs2.mp3'` 는 **상류에 파일이 없습니다.**
`Gs2`·`GS2`·`gs2`·`G%232`·`Ab2`·`As2` 전부 404 이고 `G2` 만 200 입니다(전수 확인).

실제 영향은 **소프트 페일**입니다 — 앱에서 `loadSampler('casio')` 를 불러 보니
`true` 를 돌려주고 `casioReady` 도 true 였습니다. `Tone.Sampler` 가 이웃 음으로 보간합니다.
**소리는 정상이지만** casio 를 고를 때마다 헛요청 1건과 콘솔 404 가 남습니다.

`config.js:24-27` 이 루프 목록에서 «항상 404 인 셋» 을 이미 같은 이유로 뺐습니다 —
**같은 정리를 casio 에도 하면 됩니다.**

### 3-4. [권장하지 않음 · 이유가 바뀜] 샘플 내부화

> **`02` 문서 §6.4 의 «드럼킷 11종은 자체 호스팅한다 — 한다» 를 철회할 것을 권합니다.**

`api.github.com/repos/Tonejs/audio` 를 조회하니 **`license: null`** —
그 저장소에는 **라이선스 파일이 없습니다.** 그러면:

| 행위 | 지금 | 내부화하면 |
|---|---|---|
| 성격 | 상대 서버로 **링크** | 우리 저장소로 **복사·재배포** |
| 라이선스 필요 | 사실상 불필요 | **필요 — 그런데 명시된 것이 없음** |

`02` 문서는 «저장소 190 KB 면 싸다» 는 **크기**만 따졌고 **권리**를 안 봤습니다.
크기는 실제로 349.4 KB 였습니다(실측). 하지만 크기가 문제가 아닙니다.

**대안 세 가지 — 애매하게 두지 말고 하나를 고르십시오:**

1. **그대로 둔다(권장).** 이미 `blocked()` 폴백이 실제로 동작하고, 합성 엔진만으로
   전 기능을 쓸 수 있습니다. 다만 §3-5 의 구조 정리는 합니다.
2. **CC0·퍼블릭도메인 킷으로 갈아탄다.** 드럼킷 6파일 × 몇 종이면 되고,
   그때는 마음껏 내부화할 수 있습니다. 음색이 바뀌므로 프리셋 재확인이 필요합니다.
3. **상류에 라이선스를 물어본다.** 답이 오면 1번에서 2번으로 옮기면 됩니다.

**salamander 피아노 1.26 MB 는 어느 쪽이든 내부화하지 마십시오** — 저장소(현재 2.4 MB)를
1.5배로 불리는데, 이건 **베이스 트랙의 `piano` 엔진 하나**만 씁니다.
건반의 `piano` 는 `struck.js` 합성이고 이번에 22.6배 빨라졌습니다(`03` 문서).

### 3-5. [권장] 구조 정리 — 상수를 둘로 가른다

내부화하는 것과 외부에 남는 것이 섞이면 다음 사람이 헷갈립니다.
`02` 문서 §6.4 마지막 줄이 이미 같은 말을 했습니다.


`blocked()` 문구가 «합성 엔진만으로 전 기능을 쓸 수 있습니다» 라고 이미 정직하게
말하고 있으니, 같은 정직함을 **누르기 전에** 보여주면 됩니다(예: 외부 의존 컨트롤에 배지).

### 6-1. 4번(`ASSET_BASE` 분리)을 안 한 이유

`AUDIO_BASE` 를 둘로 가르라는 `02` 문서의 조언은 **«샘플 일부를 자체 호스팅하면»** 이
전제였습니다. §3-4 에서 샘플 내부화를 접었으므로 **자체 호스팅 자산을 가리키는
JS 상수를 쓸 곳이 없습니다** — 폰트는 CSS 가, Tone.js 는 `<script src>` 가 직접 가리킵니다.
`ASSET_BASE = ''` 를 넣으면 **아무도 안 쓰는 상수**가 되어 다음 사람이 «이건 뭐지» 를
한 번 더 하게 만듭니다. 대신 `config.js` 의 `AUDIO_BASE` 위에 **여기가 유일한 외부
오리진이고 내부화하면 안 되는 이유**를 적어 두었습니다. 나중에 CC0 킷으로 갈아타
자체 호스팅분이 생기면 그때 가르면 됩니다.

### 6-3. 폰트 — 8개를 두고 5개만 받는다

`@font-face` 8벌(3패밀리 × 실제 쓰는 굵기)을 선언했지만 브라우저는 **쓰는 것만 받습니다.**
실측한 요청은 `barlow-400·500` · `barlow-condensed-400·600` · `space-mono-400` **5개**로,
`02` 문서가 Google Fonts 시절 측정한 **5개와 정확히 같습니다.** 네트워크 거동이 그대로입니다.
`Barlow 600` 은 `document.fonts.check` 가 false 인데, 이건 **아무 요소도 안 쓰기 때문**이라
정상입니다(예전에도 안 받았습니다). 저장소 200 KB 는 안 쓰는 굵기까지 포함한 값입니다 —
디자인이 나중에 그 굵기를 쓰면 그때 바로 뜹니다.

| `HAS_TONE` | **false** | **true** |
| 킷 선택 · 전체 받기 · 직접 URL | **비활성 ×3** | **활성 ×3** |
| 폰트 | 시스템 폴백 | **적용됨** |
| 베이스 `piano`·`casio` 엔진 | 사용 불가 | 사용 불가 (샘플은 원래 외부) |

**«더블클릭으로 열린다» 가 이제 샘플 한 줄만 빼고 참입니다.**
컨트롤 3개가 살아난 건 «비행기 안에서 자기 mp3 를 직접 URL 로 붙일 수 있다» 는 뜻이기도 합니다.

### 6-5. casio

`loadSampler('casio')` 요청이 **13건 중 1건 404 → 12건 전부 200** 이 됐습니다.
소리는 전에도 후에도 정상입니다(`Tone.Sampler` 가 이웃 음으로 보간).

### 6-6. 비용

저장소 **2.4 → 2.9 MB** (`fonts/` 200 KB · `vendor/` 348 KB · `styles/fonts.css` 4 KB).
검증에서 페이지 오류·콘솔 오류는 **양쪽 모두 0** 이었습니다.
